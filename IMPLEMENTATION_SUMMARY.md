#### API Endpoints (7 эндпоинтов)
1. `GET /health` - Проверка здоровья сервера
2. `POST /api/cards` - Создание карты
3. `GET /api/cards` - Получение всех карт
4. `GET /api/cards/:token` - Получение карты по токену
5. `PATCH /api/cards/:token/status` - Обновление статуса карты
6. `POST /api/pay` - Обработка платежа
7. `GET /api/pay/transactions/:token` - История транзакций
8. `GET /api/pay/terminal/:id/stats` - Статистика терминала
